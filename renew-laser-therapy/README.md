# Renew Laser Therapy

A modern, fashion-forward website for Renew Laser Therapy - Chicago's premier red light therapy center.

## Features

- **Clean, Modern Design**: Fashion-forward aesthetic with smooth animations and transitions
- **Responsive Layout**: Fully responsive design that works on all devices
- **Complete Pages**:
  - Home page with hero section and benefits overview
  - Pricing page with flexible packages and add-ons
  - About page with testimonials and team information
- **Booking Integration**: Multiple contact methods including Calendly integration
- **SEO Optimized**: Proper meta tags and semantic HTML

## Tech Stack

- React 19
- Vite
- Tailwind CSS 4
- React Router DOM

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Preview

```bash
npm run preview
```

## Preview

A standalone HTML preview is available at `/renew-laser-preview.html` in the root directory.
